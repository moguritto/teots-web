    Conexión con GitHub

    Conectado

    Puedes publicar desde este dispositivo. El código de acceso está guardado solo en este navegador.

    Para publicar hay que conectar el editor con tu cuenta de GitHub, una vez en cada dispositivo. Para mirar y probar cambios no hace falta.

    1. Abre github.com/settings/personal-access-tokens/new con la sesión de moguritto.
    2. Token name (nombre): Editor de webs. Expiration (caducidad): la más larga que te deje.
    3. Repository access (acceso a repositorios): Only select repositories (solo los elegidos) y marca los cinco: espacioteots-web, teots-web, apder-web, ianivillage-web y teotsai-web.
    4. Permissions (permisos): añade Contents (contenido) con Read and write (lectura y escritura).
    5. Pulsa Generate token (generar token), copia el código que empieza por github_pat_ y pégalo aquí:

    Cómo funciona

    1. Elige arriba la web y la página. Con Navegar puedes ir pinchando los enlaces como en la web real.
    2. En modo Editar, pincha un texto, una foto o un enlace y cámbialo. También puedes buscar el texto en la lista.
    3. Los cambios se ven al momento en amarillo. Pulsa Publicar: en uno o dos minutos está en internet.

    Si te equivocas, tras publicar aparece Deshacer. Además, cada cambio queda guardado en el historial de GitHub. Las fotos de fondo, los colores y el diseño no se cambian aquí: pídeselo a Claude.
